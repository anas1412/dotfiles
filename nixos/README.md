# NixOS config

Not a stow package — NixOS config lives in `/etc/nixos`, not `$HOME`,
so `install.sh` deliberately skips this directory.

## Use

    sudo cp nixos/*.nix /etc/nixos/
    sudo nixos-rebuild switch

`hardware-configuration.nix` is generated by the installer. Do not copy one
from another machine.

## Files

- `configuration.nix` — system: KDE, NVIDIA PRIME offload, Steam, services
- `flake.nix`         — optional: CachyOS kernel (chaotic-nyx) + home-manager
- `home.nix`          — dotfiles: zsh, p10k, aliases, PATH, git, kitty

Generated from the CachyOS install on this machine (HP Pavilion Gaming 15-dk1xxx).
